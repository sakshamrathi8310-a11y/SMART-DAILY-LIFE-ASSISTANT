# Smart Life AI

Smart Life AI is a Machine Learning based lifestyle assistant built using Python and Streamlit.

The application predicts:
- Stress Level
- Productivity Score
- Health Score

based on daily lifestyle activities such as:
- Sleep Hours
- Screen Time
- Steps Walked
- Work Hours
- Mood
- Food Quality

## Features

- Machine Learning Predictions
- Streamlit Interactive Dashboard
- Productivity, Health & Stress Analysis
- Historical Data Tracking
- AI Suggestions Integration
- Interactive Graphs using Plotly
- SQLite Database Storage

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly
- SQLite
- Joblib

## Machine Learning Models

- Random Forest Classifier
- Random Forest Regressor
- Data Preprocessing Pipeline
- Feature Engineering
